# SYNTECX_HUB_INTERNSHIP
## About This Repository
This repository contains the work completed during my Machine Learning Internship at SyntechsHub. The projects focus on real-world regression problems, applying end-to-end ML workflows from data collection and cleaning to model building and evaluation.

## Project 1:  House Price Prediction

Predict the price of a house based on features like area, location, number of rooms, and more.

What was done:

Loaded and explored the housing dataset
Handled missing values and removed outliers
Applied feature encoding for categorical variables (e.g. location, furnishing status)
Performed feature scaling for numerical columns
Built and evaluated regression models to predict house prices
Compared model performance using RMSE and R² Score

Key Skills: Data Cleaning · Feature Engineering · Regression · Model Evaluation

#  Project 2: Salary Prediction

Predict an employee's salary based on experience, education level, job role, and other factors.

What was done:
